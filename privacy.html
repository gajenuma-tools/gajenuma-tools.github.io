プライバシーポリシー

このツールは、YouTube チャンネル「ガジェ沼の本音スレ」の運営者本人だけが使う個人用ツールです。

  • Google アカウントの許可（YouTube Data API・YouTube Analytics API）は、運営者自身のチャンネルへの動画の投稿・設定と、そのチャンネルの分析データの取得にだけ使います。
  • 取得したデータと認証情報は運営者の PC の中だけに保存し、第三者に渡したり、販売したり、他の目的に使ったりしません。
  • Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
  • 許可は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
  • このツールは YouTube API サービスを使っています。YouTube 利用規約・Google プライバシーポリシーもご確認ください。
